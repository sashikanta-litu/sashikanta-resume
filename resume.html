Senior Software QA Engineer I
Celigo — Hyderabad
Jan 2019 – Sept 2026

Celigo is an iPaaS (integration platform as a service) company founded in 2011 and based in San Mateo, California, building the tooling that lets businesses automate workflows across their cloud applications. This is the platform behind the NetSuite ↔ Amazon/Shopify/eBay/Walmart/Magento 2 integrations covered below — seven years testing the same product from the inside, not a rotation across employers.

  • Sustained production quality across four marketplace integrations, holding the defect-escape rate under 5%, by defining test strategy and validating end-to-end NetSuite order, customer, item, inventory, fulfillment, cancellation, refund and settlement flows for Amazon, eBay, Walmart and Magento 2.
  • Delivered test plans, traceability matrices and release-readiness reports for 100+ releases, reaching a 93% on-time sign-off rate, by coordinating release-readiness reviews across cross-functional teams.
  • Caught data-integrity defects — record counts, mandatory fields, transformations — before release through SQL-based source-to-target validation across 5+ integration flows.
  • Cut file-processing defects by 20% by validating FTP/SFTP/FTPS adapters, including credentials, certificates, retries and archiving.
  • Reduced post-release Shopify sync incidents by 25% by building risk-based Shopify REST/Admin GraphQL API automation — cursor-based pagination, mutations, webhook idempotency checks — covering 20+ end-to-end order and fulfillment scenarios.
  • Reduced new-test authoring time by 30% for a 4–5 person team by designing reusable API test utilities for auth/token handling, assertions and data-driven execution.
  • Extended automation coverage beyond the REST API framework by building Playwright (TypeScript) suites for both UI and API layers, adding browser coverage for NetSuite integration workflows.
  • Improved CI/CD pipeline reliability, raising the automated test pass rate from 80% to 95% over about six months, by diagnosing and eliminating flaky tests tied to timing, sync and shared-dependency issues.
  • Cut mean build-failure diagnosis time from 2 hours to under 30 minutes by administering Jenkins pipelines running parallel test suites across 3+ concurrent projects, with Splunk MCP for real-time log monitoring.
  • Streamlined test case management, cutting manual upkeep of the test repository, by using Zephyr MCP to auto-generate, update and organize test cases directly from requirements and automation results.
  • Assessed API endpoint performance under load by using agentic AI (Cursor AI) to generate large synthetic datasets and replay them against target endpoints at varying concurrency levels.
  • Expanded automation scenario coverage by 30% while cutting test-authoring time by 40% by applying agentic AI workflows — Cursor Composer, ChatGPT, Claude and Grok — for scripting, test case generation and PR review, with all output manually checked.
  • Reduced sprint carry-over by 20% and improved sprint predictability across 24+ releases by facilitating Agile ceremonies — sprint planning, stand-ups, retrospectives and backlog grooming — for multiple cross-functional squads as Certified Scrum Master.
  • Built team-wide testing capability by independently mentoring and coaching 6–8 junior QA engineers over 3–4 years — leading onboarding, pairing on test design, reviewing automation code and running recurring 1:1 coaching reviews.
  • Resolved 500+ customer support tickets at a steady 10–15 per month closure rate by diagnosing and fixing configuration issues, including field-mapping misconfigurations, incorrect NetSuite tax setup and inventory configuration errors.
  • Closed a native reporting gap by acting as the bridge between customers and Product Management — for example, reverse-engineering Amazon's missing discount-tax percentage from settlement report data when the SP-API order endpoint didn't return it, then partnering with PMs through the FRD process.

Shopify ↔ NetSuite

  • End-to-end flows across customer sync, product catalog, order import, inventory, fulfillment, cancellations and refunds using Shopify's Admin GraphQL API (cursor-based pagination, mutations, schema/error validation).

eBay ↔ NetSuite

Walmart ↔ NetSuite

Magento 2 ↔ NetSuite
